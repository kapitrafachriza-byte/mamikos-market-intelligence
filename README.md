# Mamikos Market Intelligence

Proyek analisis pasar, pemodelan *machine learning*, dan visualisasi dasbor interaktif berdasarkan data kos dari Mamikos.

## Struktur Direktori

```text
mamikos-market-intelligence/
├── data/
│   ├── raw/                # Data mentah hasil scraping
│   └── processed/          # Data bersih setelah cleaning & ML
├── notebooks/
│   ├── 01_scraping.ipynb   # Script / notebook web scraping
│   └── 02_eda_and_ml.ipynb # Eksplorasi data, feature engineering, modeling
├── dashboard/
│   ├── dashboard.pbix      # File kerja Power BI Desktop
│   └── screenshots/        # Gambar tangkapan layar tiap halaman dasbor
├── README.md               # Halaman depan proyek
└── requirements.txt        # Library Python yang dipakai
```
